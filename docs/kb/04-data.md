# Project data

## Export projects
Owners and Admins can export project data from Settings > Data > Export. An export is a ZIP file containing project CSV files and uploaded attachments. Export download links expire after 24 hours; create a new export if a download link has expired.

## Deleted project recovery
Deleted projects stay in the workspace Trash for 30 days. Owners and Admins can restore a deleted project from Settings > Trash > Restore. Once a project has been permanently removed from Trash, MeadowDesk cannot restore it.

## Attachment limits
Each uploaded attachment can be at most 25 MB. Supported attachment formats are PDF, PNG, JPG, TXT, and CSV. Split a larger document or reduce its size before uploading; the limit cannot be increased in this demo product.
