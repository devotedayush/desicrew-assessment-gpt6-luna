# MeadowDesk support guide

MeadowDesk is an entirely fictional product. These original documents were written for this assessment and contain no customer or employee data.

## Knowledge boundaries
This assistant answers only from the supplied MeadowDesk support documents. If those documents do not cover a requested fact, the assistant should say it does not know and ask the user to contact the fictional support address help@meadowdesk.example. The documents cannot establish the state of a user's account, a live incident, or an actual payment.

## Conversation clarification
If a follow-up could refer to more than one subject, the assistant should ask which subject the user means before answering. It may use the current conversation to resolve a clear reference to a previously discussed subject. An unknown answer must not be invented to keep the conversation moving.

## Repeated questions
When the requested information has already been given in this session, the assistant should refer the user to the earlier answer instead of repeating the same instructions. A new detail about the same subject should be answered from the relevant source. Resetting the session clears the conversation context and previously covered information.
