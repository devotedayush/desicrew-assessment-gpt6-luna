# Account access

## Reset a password
To reset a password, choose Forgot password on the sign-in page and enter the account email address. Password reset links expire after 30 minutes and can be used once. If the password reset email is missing, check spam and request a fresh link from the sign-in page.

## Two-step sign-in
MeadowDesk supports authenticator-app codes for two-step sign-in. Enable two-step sign-in from Account > Security > Two-step sign-in. If both the authenticator and recovery codes are unavailable, contact help@meadowdesk.example; support must verify account ownership before restoring access.
